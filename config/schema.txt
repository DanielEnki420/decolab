# Decolab configuration schema
#
# One setting per line: KEY TYPE REQUIRED
#   REQUIRED is "required" or "optional" (optional settings may be empty).
#
# Types:
#   user     Linux user name, not root
#   abspath  absolute path without spaces, "..", "//" or trailing slash
#   tz       time zone such as Europe/Berlin or UTC
#   iface    network interface name
#   ipv4     IPv4 address
#   cidr     IPv4 network in CIDR form, aligned to its prefix
#   port     TCP port 1-65535
#   yesno    yes | no
#   auto     auto | yes | no
#   days     whole number 1-365
#   tailnet  Tailscale tailnet name (the part before .ts.net)
#   notify   telegram | ntfy | none
#   restic   restic repository (absolute path or sftp:, rest:, s3:, b2:, azure:, gs:, swift:, rclone:)
#
# The file is read by bin/decolab-config and lib/config.sh.
# Keep it a plain list: no quoting, no inline comments.
